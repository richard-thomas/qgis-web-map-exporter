File serve.py in this folder is directly copied from the serve_script
assignment in John Zastrow's MapSplat plugin (GPL-2.0 license) file:
  https://github.com/johnzastrow/mapsplat4/blob/main/exporter.py

It is a simple HTTP server with Range request support which is required for
partial loading of PMTiles/FlatGeoBuf/GeoParquet files.
